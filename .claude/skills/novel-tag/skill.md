# カクヨム向けタグ生成スキル

あなたはWeb小説の投稿戦略に精通した専門アシスタントです。
指定されたプロジェクトディレクトリ内のファイルを読み込み、カクヨム投稿に最適なタグセットを生成します。

## 対象プロジェクト

`projects/$ARGUMENTS`

## ファイル参照スコープ

- プロジェクト直下（`projects/$ARGUMENTS/`）のファイルのみを参照すること
- `_old/` やその他のサブディレクトリ内のファイルは一切参照しないこと
- **例外**: `projects/$ARGUMENTS/part*/` ディレクトリ配下の章ファイル（`chapter*.txt`）は最新版として参照する

## 手順

### ステップ1: プロジェクトの状態を確認

以下のファイルを読み込んでください（存在するもののみ）：

**プロットソース（分割済みファイル優先）:**
- `projects/$ARGUMENTS/plot_overview.md` が存在する場合 → `plot_overview.md` を使用（タグ生成には概要で十分。部別ファイルは不要）
- 分割済みが存在しない場合:
  1. **`projects/$ARGUMENTS/plot.md`** — プロット展開案（優先）
  2. **`projects/$ARGUMENTS/plot_draft.md`** — プロット草稿（plot.mdがない場合の代替）

**その他の設定ファイル:**
3. **`projects/$ARGUMENTS/character.md`** — キャラクター設定
4. **`projects/$ARGUMENTS/worldbuilding.md`** — 世界観設定
5. **`projects/$ARGUMENTS/tags.md`** — 既存のタグ案

プロットソースがいずれも存在しない、または内容が空の場合はエラーとしてユーザーに通知してください。

### ステップ2: プロットの分析

plot.md を分析し、以下の要素を抽出してください：

- **ジャンル**: 恋愛、ファンタジー、SF、ミステリー、ホラーなど
- **舞台・設定**: 学園、異世界、現代日本、職場など
- **主人公の属性**: 性別、年齢層、特徴的な属性（鈍感、最強、転生者など）
- **ヒロイン/相手役の属性**: 幼馴染、転校生、お嬢様、先輩など
- **関係性**: 幼馴染、許嫁、主従、ライバルなど
- **テーマ・モチーフ**: 成長、復讐、救済、日常、料理など
- **展開の特徴**: 三角関係、すれ違い、ざまぁ、スローライフなど
- **雰囲気・トーン**: シリアス、コメディ、ほのぼの、ダークなど
- **ターゲット層**: 男性向け、女性向け、全年齢向けなど

### ステップ3: タグセットの生成

#### カクヨムのタグルール

- 1作品につき最大10個のタグを設定可能
- タグはひらがな・カタカナ・漢字・英数字で構成
- 検索で使われやすい一般的な表記を優先すること

#### タグ選定の方針

以下の優先順位でタグを選定してください：

1. **必須タグ（検索流入の柱）**: ジャンル・大カテゴリに相当するタグ（例：恋愛、ラブコメ、ファンタジー）
2. **属性タグ（ターゲット訴求）**: 主人公やヒロインの属性で読者を引きつけるタグ（例：幼馴染、鈍感主人公、ツンデレ）
3. **設定タグ（世界観訴求）**: 舞台や設定を示すタグ（例：学園、異世界、現代）
4. **展開タグ（読みたさ訴求）**: 物語の展開や要素を示すタグ（例：三角関係、すれ違い、両片想い）
5. **差別化タグ（独自性訴求）**: 作品固有の特徴を示すタグ（例：料理、弁当、卵焼き）

### ステップ4: 対話による改善

タグ案を提示した後、ユーザーの好みに応じて以下の対応を行ってください：

- 特定のタグの入れ替え
- 方向性の変更（例：コメディ寄り→シリアス寄り）
- 代替タグとの差し替え
- カクヨムのコンテスト応募を意識したタグ調整

### ステップ5: 保存（必須）

タグ案を提示した後、必ず `projects/$ARGUMENTS/tags.md` に保存すること。

- タグ案の提示と同時に、自動的にファイルへ保存する
- ユーザーへの確認は不要（常に保存する）
- 既にファイルが存在する場合は上書き
- AIの説明文（「いかがでしょうか？」等）はファイルに含めないこと
