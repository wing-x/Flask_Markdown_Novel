# 執筆契約テンプレート

**このファイルの目的**: 各部を書き始める前に埋めるテンプレート。`novel-plot` モードF (プロット分割) の後、または部単位の執筆開始前に使う。`projects/{作品名}/writing_contract_part{NN}.md` として保存する想定。

**根本思想**: 「入れる情報を増やすより、入れない情報を選ぶ」。この契約は**その部を書くときに Claude が見るべき最小セット**を定義する。

参照元: `novel-plot` (部分割時)、`novel-write` (部の最初の章を生成するとき)

## この部の文体ダイナミクス

各章の感情強度に応じた文体指示を定義する。「全てのシーンを同じ温度で書く」AI生成文の最大の弱点を防ぐための設計図。

| 章 | 感情強度 | 文体指示 |
|---|---------|---------|
| 第{N}話 | 静（日常） | (例) 標準テンポ、五感描写厚め、内心は控えめ |
| 第{N+1}話 | 中（緊張） | (例) やや短文寄り、内心5個以下、伏線の設置に集中 |
| 第{N+2}話 | 大（クライマックス） | (例) 短文連打、現在形、内心なし、行動と身体反応のみ |
| 第{N+3}話 | 笑（コメディ） | (例) 台詞主体、地の文最小、ツッコミ前に地の文を挟まない |
| 第{N+4}話 | 小（余韻） | (例) 長文、情景描写中心、静かな会話 |

**記入のコツ**:
- 同じ感情強度の章を3話以上連続させない
- 「大」の前には必ず「静」か「中」の溜めを置く
- コメディを挟むことで読者の疲労をリセットする

## この部の執筆時に参照すべきファイル (最小セット)

**Claude はこれ以外のファイルを読まない**。

- `projects/{作品名}/character.md` (またはシリーズ聖典 `characters_master.md`)
- `projects/{作品名}/worldbuilding.md`
- プロット（優先順位「話単位 > 部単位 > 未分割」）:
  - 話単位: `projects/{作品名}/plot_chapters/chapter{NN}.md` または `plot_draft_chapters/chapter{NN}.md`（書いている話のファイルのみ）
  - 部単位: `projects/{作品名}/plot_part{NN}.md`（この部のプロットのみ）
- タイムライン（同じ優先順位）:
  - 話単位: `projects/{作品名}/timeline_chapters/chapter{NN}.md`（書いている話のファイルのみ）
  - 部単位: `projects/{作品名}/timeline_part{NN}.md`（この部のタイムラインのみ）
- `projects/{作品名}/writing_contract_part{NN}.md` (このファイル)
- 直前の部の**最終章ファイル** (部の最初の章を書くときのみ)
- 直前の章ファイル (連続する章を書くときのみ)
- `.claude/skills/_shared/references/style-rules.md`
- `.claude/skills/_shared/references/forbidden-patterns.md`

### 読まないファイル (執筆時)

- `plot_draft_*` (草稿・設計メモ)
- `idea_notes.md` (企画メモ)
- 設計系メモファイル (「読者への効果」「伏線設計メモ」等を含むもの)
- 現在の部と関係ない他部のプロット・タイムライン

## 部完了時のチェック

この部の執筆を終えたら、以下を確認:

- [ ] 「この部のゴール」の各項目は達成されたか
- [ ] 「やってはいけないこと」に抵触していないか
- [ ] 設置予定の伏線は全て書かれたか
- [ ] 回収予定の伏線は全て書かれたか
- [ ] 感情線の到達点に各キャラが到達したか
- [ ] `handoff-document.md` (部間ハンドオフ文書) を作成したか
