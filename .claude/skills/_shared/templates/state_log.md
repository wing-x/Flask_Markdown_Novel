# 状態ログ（state_log.md テンプレート）

**このファイルの目的**: 複数話にまたがって変動する数値・履歴・状態の**単一情報源（Single Source of Truth）**。`/novel-check-state` による全話横断チェックの基準ファイルとして使う。

**設置場所**: `projects/{作品名}/state_log.md`

---

## 運用ルール

1. **更新順序の厳守**: 数値・履歴を変更する修正をしたら、**まず本ファイルを更新→該当話の本文を修正**。逆順は禁止
2. **回数依存セリフは原則回避**: 「○回目の○○」「○人目の○○」のような回数を直接言及するセリフは、修正のたびにズレる構造的弱点がある。書く前に本ファイルで現在のカウントを確認する
3. **未確定要素は空欄にせず「未定」と明記**: 空欄は記入忘れと区別がつかないため
4. **テーブル外の自由記述は最小限**: 矛盾検出は構造化された情報の方が機械的に行える
5. **新カテゴリは自由に追加してよい**: 作品固有の「これは追跡しておくべき」と気づいたものは見出しごと足す
