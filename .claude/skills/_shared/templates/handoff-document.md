# 部間ハンドオフ文書テンプレート

**このファイルの目的**: ある部を書き終えて次の部に移るときに作る引き継ぎ文書。次の部を書く Claude は**このハンドオフ + 次の部の執筆契約 + 次の部のプロット**だけを読めば書き始められる状態を目指す。`projects/{作品名}/handoff_after_part{NN}.md` として保存する想定。

**根本思想**: 前の部の本文をすべて読み返させるのではなく、**要約と確定事項だけ**を渡す。「入れる情報を増やすより、入れない情報を選ぶ」。

参照元: `novel-write` (部の執筆完了時)、`novel-plot` (次の部のプロット作成時)

## 次の部の開始時に読むべき最小セット

次の部を書く Claude が読むべきファイル一覧。**これ以外は読まない**。

- `projects/{作品名}/character.md` (またはシリーズ聖典 `characters_master.md`)
- `projects/{作品名}/worldbuilding.md`
- `projects/{作品名}/handoff_after_part{前のN}.md` (このファイル)
- `projects/{作品名}/writing_contract_part{次のN}.md`
- プロット（優先順位「話単位 > 部単位」）: `projects/{作品名}/plot_draft_chapters/chapter{XX}.md`（次の部に属する話のファイル群）または `projects/{作品名}/plot_part{次のN}.md`
- タイムライン（同じ優先順位）: `projects/{作品名}/timeline_chapters/chapter{XX}.md`（次の部に属する話のファイル群）または `projects/{作品名}/timeline_part{次のN}.md`
- この部の**最終章のファイル** (`chapter{XX}.txt`)
- `.claude/skills/_shared/references/style-rules.md`
- `.claude/skills/_shared/references/forbidden-patterns.md`

### 読まないファイル

- この部の本文 (最終章を除く)
- この部より前のハンドオフ文書
- 設計メモ系ファイル
