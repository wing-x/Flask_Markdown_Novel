# 禁止パターン集

**このファイルの目的**: 執筆中に陥りがちな AI 臭・説明臭パターンを列挙し、理由と代替案を示す。抽象的な指示ではなく具体的な「やってはいけない書き方」のカタログ。

参照元: `novel-write` (生成時)、`novel-check` (検出時)、`novel-fix` (書き換え時)

---

## 【絶対禁止】

### 1. キャラが自分のキャラ設定を内心で解説する

**なぜ禁止**: 設定は読者が本文を読んで推測するもの。キャラ自身に「自分はこういう人間だ」と言わせると小説が説明書になる。

**✗悪い例**:
```
（俺は昔から人付き合いが苦手で、特に女性と話すと頭が真っ白になる性格だ）
```

**◎代替**: 状況で見せる。
```
 千影に話しかけられた瞬間、柊一の頭から言葉が消えた。代わりに「えっと」と「はい」が交互に出てくる。
```

---

### 2. 「〜という自覚」「〜という事実」「〜であること」等の抽象名詞化の多用

**なぜ禁止**: 地の文が抽象化されると情景が消え、解説書の文体になる。

**✗悪い例**:
```
柊一は自分が千影に惹かれているという事実を認めざるを得なかった。
```

**◎代替**: 動作と感覚で書く。
```
 千影が笑うと、柊一はいつも豆の袋を握る指に力が入る。認めたくなかった。でも、指は正直だ。
```

---

### 3. 「○○は△△な人間だった」等のキャラ自身による自己規定

**なぜ禁止**: キャラが自分を俯瞰で評価するのは小説ではなくナレーション。

**✗悪い例**:
```
（私は昔から、誰かに頼ることが苦手な人間だった）
```

**◎代替**: 頼れなかった場面そのものを書く。

---

### 4. 読者への説明をキャラの台詞や内心に混ぜ込む

**なぜ禁止**: 「ご存知の通り」話法。登場人物同士が既に知っていることを説明口調で喋るのは不自然。

**✗悪い例**:
```
「ご存知の通り、このカフェは三年前から駅前で営業していて——」
```

**◎代替**: 情報は地の文の一瞬の描写、あるいは別キャラへの説明として切り分ける。

---

### 5. テーマの言語化をキャラにさせる

**なぜ禁止**: 「これが恋というものか」「人間の本質とは——」とキャラに言わせた瞬間、読者が気づく喜びが消える。

**✗悪い例**:
```
（ああ、これが恋というものなのか。人が誰かを想うというのは、こんなにも苦しいものなのか）
```

**◎代替**: 恋だと言わず、恋をしている者の行動を書く。

---

### 6. 複数キャラの内心を同一段落でザッピングする

**なぜ禁止**: 視点が混濁し、読者がどのキャラに感情移入すべきか分からなくなる (POV ブリーク)。

**✗悪い例**:
```
 柊一は胸が苦しかった。千影も同じ気持ちだった。律は二人の間の空気を感じ取って少し寂しくなった。
```

**◎代替**: 1シーン1視点を守る。他キャラの内心は外面 (表情・仕草・声色) からの推測として書く。

---

## 【AI臭いとされがちな表現】

### 7. 「〜という気がする」「〜なのかもしれない」の多用

**なぜ避ける**: 断言を避ける言い回しを繰り返すと、地の文が自信なさげな学生レポートのトーンになる。

**代替**: 断定するか、身体感覚で置き換える。「気がする」→「指先が温かくなった」。

---

### 8. 過剰に独創的な比喩

**なぜ避ける**: 「まるで星屑の絨毯を踏みしめるような足取りで」等、凝りすぎた比喩は読者を止める。普通の表現で足りる場面では普通に書く。

**代替**: 日常語。「ゆっくりとした足取りで」で十分なことが多い。

---

### 9. 「まるで〜のように」の多用

**なぜ避ける**: 1ページに3つ以上出ると、比喩が弱くなる。本当に必要な1発だけ残す。

---

### 10. 同じ段落で同じ語を繰り返す (意図的な反復を除く)

**なぜ避ける**: 語彙の貧困に見える。ただし A-5 のような「反復による情感表現」は意図的に行うので別。

**✗悪い例**:
```
 柊一は豆を挽いた。豆の香りが漂う。豆を袋に戻す。豆棚を整える。
```

**◎代替**: 語を変える、あるいは省略する。「柊一は豆を挽いた。香りが漂う。袋に戻し、棚を整える」。

---

### 11. 冗長な副詞の連発

**なぜ避ける**: 「とても」「非常に」「本当に」「まさに」を連発すると、修飾が強調ではなくノイズになる。

**代替**: 副詞を削り、動詞を強い語に置き換える。「とても走った」→「駆け出した」。

---

### 12. 「〜のだった」「〜なのであった」調の古風な締め

**なぜ避ける**: 現代 Web 小説のトーンから浮く。意図的な語り芸として使う場合を除き避ける。

---

## 【構造的に避けるべきパターン】

### 13. 一つのシーンに情報を詰め込みすぎる

**なぜ避ける**: 1シーンで「世界観説明 + キャラ紹介 + 伏線 + 感情の転換」を全部やると、どれも印象に残らない。1シーン1目的に絞る。

---

### 14. 伏線回収をキャラに気づかせて解説させる

**✗悪い例**:
```
「あっ! そうか、あの時のあれはこういう意味だったのか!」
```

**◎代替**: 気づきは動作・表情・一言で示し、解説はしない。読者に繋げさせる。

---

### 15. 「読者への効果」を本文に書く (設計メモと本文の混同)

**なぜ禁止**: プロットの「読者への効果」「伏線メモ」「引き」等のメタ情報をそのまま地の文に書いてはならない。これは設計メモであって本文ではない。

---

### 16. 部の結末や伏線の全容を途中のキャラに把握させる

**なぜ避ける**: キャラは「その時点で知っていることしか知らない」のが原則。未来の展開を前提にした先読み行動・先読み内心を書かない。

**検証方法**: `timeline.md` の「キャラクター知識・認知の変遷」と照合する。

---

### 17. 状況説明を台詞でやらせる

**✗悪い例**:
```
「ご存知の通り、我々の街は三年前の大火で半分が焼け、その後の復興で——」
```

**◎代替**: 地の文の一瞬の描写、あるいは新規登場人物への自然な説明として切り分ける。

---

### 18. 全知視点ナレーションで章を締める・次巻/次部/次章の予告ナレーション

**なぜ禁止**: 「読者だけが、それを知っている」「——しかし読者は知っている〜」「第二部で、この店は壊れるように動き始める」のような、物語世界の外から作者が読者に直接語りかける文は、第四の壁を破り作品の没入を壊す。これらはプロットの「読者への効果」「次章への橋渡し」セクションの思考が本文に漏れた典型パターンであり、作品の品格を一気に落とす。特に章末にこの種のナレーションを入れるのは、「読者だけが知っている」勘違い構造を作者が自ら種明かしすることと同じで、コメディの構造そのものを殺す。

**✗悪い例**:
```
　読者だけが、それを知っている。
```
```
　——しかし読者は知っている。この店の全員が片想いをしていることを。全員が誰かを見ていて、そして全員が、見当違いの方向を向いていることを。
```
```
　第二部で、この店は、壊れるように動き始める。
```

**◎代替**: その章の最後の視点人物の行動・感覚・内心で締める。予告的な効果が必要なら、視点人物の違和感・予感として内面から書く。
```
　柊一はカップを口元に運んだ。一口。苦味と、残り香と、いつもと同じ味。
　——気のせいではなかった。
```

**検証方法**: 章末の最後の3段落に「読者」「第N部で」「やがて」「まもなく」「後に」等の全知視点語が含まれていないか確認する。含まれていたら視点人物の内面描写に置き換える。

---

### 19. その話時点で未登場の設定要素（メニュー・キャラ・イベント）を先行描写する

**なぜ禁止**: 連載小説では設定要素（メニュー・キャラ・アイテム・イベント）が時系列に沿って段階的に導入される。後の章で誕生する要素を前の章の背景描写でさらっと出すと、後続章での正式導入シーンが無意味化し、プロットの設計が崩れる。「登場」だけでなく「言及」もこのパターンに含まれる。

**典型事例**: 第10話で高峰琴葉の要望から誕生予定のオムライスを、第9話の背景描写で「蓮司がオムライスを注文して」と書いてしまう。読者は第10話の「オムライス誕生シーン」で「既に前話で出てたよね?」と違和感を覚える。

**✗悪い例**（第9話。オムライスは第10話から登場予定）:
```
　蓮司がオムライスを注文して、柊一に「うるさい」と言われていた。
```

**◎代替**: その時点で既に登場済みの要素のみで描写する。
```
　蓮司が鉄板ナポリタンの大盛りを注文して、柊一に「うるさい」と言われていた。
```

**検証方法**: 執筆前にプロットの配置表（メニュー配置表・キャラ登場表・イベント配置表）を確認し、「この話時点で既に登場した要素」のリストを頭に入れる。背景描写で登場要素に触れる際は、そのリスト内のものだけを使う。

---

### 20. キャラの台詞の口癖・言い回しを地の文に引き込む

**なぜ禁止**: 「うちのブレンド」「俺様」「〜だぜ」のようにキャラ固有の言い回し・口癖を地の文に書くと、地の文がそのキャラの主観に寄ってしまい、三人称視点の中立性が崩れる。台詞では自然でも、地の文では作者が台詞を真似ているように見え、品格が落ちる。特に店主・主人公格のキャラの口癖ほど地の文に漏れやすい。

**典型事例**: 柊一の台詞「うちのブレンドだ」は自然。しかしそれが地の文「柊一はカップにうちのブレンドを注いだ」になると、地の文が柊一の一人称視点になってしまう。三人称で書く地の文は「ブレンド」と中立的に。

**✗悪い例**（地の文）:
```
　柊一はカウンターの中で、自分用のカップにうちのブレンドを注いだ。
```
```
　豆を挽く音が店に響き始めた。うちのブレンド。
```

**◎代替**: 台詞での口癖は維持し、地の文は中立的な表現にする。
```
　柊一はカウンターの中で、自分用のカップにブレンドを注いだ。
```
```
　豆を挽く音が店に響き始めた。ブレンド。
```
台詞内では引き続き許容: `「うちのブレンドだ」`

**検証方法**: 地の文中に一人称代名詞（「うち」「我が」等）や、キャラ固有の言い回しが出ていないか確認する。台詞を地の文に引きずっていないかチェックする。

---

### 21. 全キャラ共通の身体反応で恋心・動揺を表現する

**なぜ禁止**: 「心臓が跳ねた」「耳が赤くなった」「手が震えた」を全キャラで使い回すと、恋心の表現が**金太郎飴**になる。読者は誰の恋も同じに見え、キャラクターの個性が文章レベルで消失する。

**✗悪い例** (全員同じ反応):
```
千影の心臓が跳ねた。（3話）
律の心臓が一段跳ねた。（8話）
彩音の心臓が一段跳ねた。（15話）
柊一の胸の奥で何かが跳ねた。（20話）
```
→ 4人全員「心臓が跳ねる」。キャラの差が見えない。

**◎代替**: `character.md` の「感情表現パターン」を参照し、キャラごとに異なる身体反応で恋心を表現する。

```
千影: 指先が冷たくなった。エプロンの裾を掴む力が、少しだけ強くなった。
律:   ペンを回す速度が上がった。ノートの端に無意味な直線を3本引いた。
彩音: 早口になった。言葉が2つ先を走り始めた。
柊一: カップを磨く角度が、ほんの半拍だけ遅くなった。
```

**検証方法**: 「心臓」「跳ねた」「鳴った」「赤くなった」で章内をgrepし、複数キャラで同一表現が使われていないか確認する。使われていたら `character.md` の身体反応パターンに差し替える。使用上限は `style-rules.md` G-1 参照。

### 22. 「〇〇は気づいていない/知らない」で章を締める

**なぜ禁止**: #18（全知視点ナレーション）の最も頻出する亜種。読者が「あ、この二人すれ違ってる！」と自分で気づく快感を、作者が先に言葉にしてしまうことで奪っている。すれ違いラブコメの最大の武器を自ら破壊するパターン。

**✗悪い例**:
```
千影は気づいていない。マスターの手が止まったことにも、自分の笑い方が素に戻っていたことにも。
```
```
——彩音は律の手が引っ込んだ本当の理由を、一ミリもわからなかった。
```
```
律が今夜の「余ったから」の意味をまだ自分でも言語化できていないことも、——彩音は知らない。
```

**◎代替**: すれ違いは「的外れな行動」の描写だけで示す。読者に自分で気づかせる。

```
千影はエプロンの裾を直した。いつもの動作に戻る。
——カウンターの向こうで、柊一が磨いていたカップを二度棚に戻し損ねたことには、目もくれなかった。
```
→ 「気づいていない」と書かずに、千影が柊一の動揺を見ていない事実だけを描写する。読者が「気づいてないじゃん！」とツッコむ余地が生まれる。

**検証方法**: 章末の最後の3段落に「気づいていない」「知らない」「わからなかった」「気づかなかった」が含まれていないか確認する。含まれていたら行動描写に置き換える。

### 23. 場面転換を毎回ダッシュ「——」で行う

**なぜ禁止**: ダッシュによる場面転換（「——翌日。マンハッタン。午後。」等）は映画的で効果的だが、全場面転換をこのパターンで行うと、転換自体が機械的になり、場面の切り替わりに驚きや余韻がなくなる。読者は「あ、またダッシュだから場面が変わるな」と予測してしまう。

**✗悪い例** (1章内の全転換がダッシュ):
```
——同じ日の夕方。マンハッタン。
（シーン）
——翌日。マンハッタン。午後。
（シーン）
——その日の閉店後。
（シーン）
——三日後。
```

**◎代替**: ダッシュ転換は1章2回まで。他は以下の手法を使う。

```
（空行2行のみ — 描写で新場面を示す）
　夕日がカウンターの上を横切っていた。店内に客は三人だけだった。

（音で繋ぐ）
　ドアベルが鳴った。冷たい風と一緒に、律が入ってきた。

（対比で繋ぐ）
　朝のコーヒーはまだ温かかった。
　同じカップが冷め切った頃、千影はようやく口を開いた。

（人物の動きで繋ぐ）
　彩音は商店街を抜けた。信号を二つ渡り、マンションのエントランスに辿り着く。
```

**検証方法**: 1章内の場面転換箇所を数え、ダッシュ「——」による転換が3回以上あれば、3回目以降を別手法に置き換える。

---

### 24. キャラクターが感情名詞を直接口にする

**なぜ禁止**: 「嬉しい」「悲しい」「怖い」「好き」「愛してる」等の感情名詞を台詞で直接言わせると、読者が自分で感情を読み取る余地がなくなる。台詞は行動の一種であり、感情の「説明」ではない。**ただしクライマックス（告白・決別・和解等の決定的場面）では解禁**——だからこそ決定的場面の台詞が重くなる。

**✗悪い例** (日常場面で感情を直接言う):
```
律「先生のお菓子、嬉しいです」
千影「みんなが来てくれて、楽しい」
彩音「律くんといると安心する」
```

**◎代替**: 感情を行動・反応・選択で示す。
```
律「先生、……おかわりって、ありますか」
 ——食べ終わったクッキーの皿を、律は両手で差し出した。
千影「今日は、閉店時間が早く感じるね」
彩音「律くんの隣って、なんか歩くペース合うんだよね」
```
→ 「嬉しい」「楽しい」「安心」を一度も言わずに、全て伝わっている。

**例外（解禁条件）**: 物語のクライマックス — 告白・決別・和解・覚悟を決める場面。日常で一切言わなかった感情語を、決定的瞬間にだけ口にすることで、その一言の重みが最大化される。

**検証方法**: 台詞（「」内）に「嬉しい」「悲しい」「怖い」「寂しい」「楽しい」「好き」「嫌い」「愛してる」「幸せ」「辛い」「苦しい」「安心」等の感情形容詞・名詞が含まれていないか検索する。含まれていた場合、その場面がクライマックスかどうかを判定し、クライマックスでなければ行動描写に置き換える。

---

### 25. 触感・五感の解説的内面化

**なぜ禁止**: 身体接触・触感・五感的事象の直後に、視点キャラ複数名分の長い解釈モノローグを連続配置すると、触感が読者に届く前に「解説」で上書きされる。読者が触感の余韻を自分で受け取る時間を奪う。語り手が先に受け取って、噛み砕いて、結論まで添えて差し出してしまうと、出来事→解説→出来事→解説の等間隔リズムができあがり、文章が単調に感じられる。

**典型事例**: 手首冷却・手の重なり・吐息の交差等の身体接触シーンで、両側の内心を交互に長く展開する。

**✗悪い例**:
```
　柊一が千影の手首を冷水に浸した。

（細い。男にしては——いや、栄養が）
（明日、賄いでも出すか）

　千影は唇を噛んだ。

（マスターの手が）
（私の手首をつかんでる）
（冷たい水と温かい指）
（心臓、うるさいな）
```
→ 接触の余韻を、二人分の独白が押しのける。読者が受け取る前に全部解説されている。

**◎代替**: 身体接触の直後は最小限の身体描写で止め、解釈を読者に渡す。

```
　柊一が千影の手首を冷水に浸した。
　水の冷たさと指の温かさの差だけが、まだ皮膚の上に残っている気がした。
```
→ 最後の一文で止める。読者が触感を自分で受け取る。

**検証方法**: 身体接触・五感的事象を含む段落の直後3段落以内に、視点キャラ複数名分の括弧書き独白（2行以上）が連続している場合、削減対象。`style-rules.md` A-7 と併せて判定する。

### 26. テーマワードの自己貼り直し

**なぜ禁止**: 作品のテーマを構成するキーワード（例：「嘘」「正直」「演技」「役作り」等）を、当該キャラ本人が自分の状態に対して内心で繰り返し貼り直すと、テーマが「キャラの自覚」として処理され、読者の中で薄まる。テーマは登場人物が気づいていない場所で動いているとき、いちばん強く効く。

逆に、テーマワードは「外部からの観察」「他キャラのセリフ・独白」「地の文の象徴配置」として現れるとき、最大効率になる。

**典型事例**: 「嘘をついている」キャラが、自分の状態を内心で「嘘はついてない」「正直だった」「言えなかっただけ」と繰り返しラベリングする。テーマワードを本人に何度も発音させると、読者の中でそのキーワードが摩耗する。

**✗悪い例**（タイトル『正直者はいない』作品で千影視点）:
```
（私は嘘はついてない）
（正直だった）
（……言えなかっただけ）
（嘘はついてない）
```
→ 千影本人が自分の状態にテーマを貼り直し続けると、読者の中で「嘘」というキーワードが薄まる。

**◎代替A**（行動だけで示す）:
```
　千影は笑顔を作った。低い声を、半音だけ整える。
　エプロンのポケットで、ヘアピンを奥に押し込んだ。
```
→ 一度も「嘘」と思わせず、嘘をついている状態を描く。

**◎代替B**（他キャラの呟きでテーマを置く）:
```
　誰に向けるでもなく、
「珈琲は嘘をつかない」
　柊一はそう呟いた。
```
→ テーマワードを外部視点から落とす。

**検証方法**: プロジェクトの `rules.md` に「テーマワード管理」セクションがある場合、そのテーブルの **B区分**（自己ラベリング・削減候補）に該当するパターンを各章で検出する。`rules.md` に設定がない作品では、作品の中心テーマを構成する語を著者が指定すれば同様の判定が可能。
