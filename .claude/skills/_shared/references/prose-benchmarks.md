# 密度ベンチマーク集（Prose Benchmarks）

**このファイルの目的**: 「情報密度のリズム」「触感の余韻」「キャラの性格そのものを示す独白」のお手本を、実作品から引用付きで提示する。抽象的なルール記述では伝わらない「このリズム・この密度・この含み」を、具体例で示すための参照集。

参照元: `novel-write`（執筆前の参照）、`novel-fix` モードF（削減後の妥当性検査の照らし合わせ先）、`novel-check` Part 3（検出基準の感覚校正）

**使い方**:
- 執筆前に **少なくとも1ベンチマークをスキャン** し、密度感覚を頭に入れてから書き始める
- 削減後に「このリズム感に近づいているか」を照らす
- 抽象ルール（`style-rules.md` A-7 / A-8、`forbidden-patterns.md` #25 / #26）と組み合わせて使う

## ベンチマーク1：余韻で止める ―― 触感の最後の一文を読者に渡す

**出典**: 第五話「嘘をつかない男」（手首冷却シーン末尾）

**シーン**: バイトの千影が客に肩を押されてコーヒーを手の甲にこぼす。店長の柊一が氷水とタオルを用意して、千影の手首を掴んで冷水に沈める。

**前段の構造（参考のため要約のみ。本文引用は終盤の余韻部分のみ）**:
本シーンの中段では、千影と柊一の両側の独白が確かに並ぶ（「（マスターの手が）（私の手首をつかんでる）（……心臓、うるさいな）」「（——細い）（男にしては、細いな）」）。これは `forbidden-patterns.md` #25 が指摘する「触感の解説的内面化」の事例で、ベンチマークとしては推奨しない。

**◎ベンチマーク**: シーンの**最後の一文**で、すべての解釈を捨てて触感だけを残している箇所。

```
　千影はタオル越しに自分の手首の骨をそっと指で確かめた。柊一の指の感触はもうそこにはない。けれど水の冷たさと指の温かさの差だけが、まだ皮膚の上に残っている気がした。
```

**なぜこの一文が効くか**:

1. **解釈ゼロ**: 「冷たい水」「温かい指」「皮膚の上に残っている」だけ。「だから〜」「つまり〜」「私は〜と感じた」が一切ない
2. **触感の差分だけを残す**: 「水＝冷」「指＝温」の対比だけが地の文に置かれ、その意味づけは読者に丸投げされる
3. **「気がした」の保留**: 断定せず「気がした」で終わることで、千影が自分の感情をまだ言語化できていない状態が、文の形そのもので表現されている
4. **次の段落で時間が飛ぶ**: この一文の直後で店内の場面が切り替わる。読者は触感を持ち越したまま次の場面へ進む

**学べる原則**:

- 身体接触シーンは「最後の一文」で止める。その前にすでに全部解説してしまっていないかを確認する
- 触感は「対比だけ」を残す（冷と温、硬と柔、軽と重）。意味は読者に渡す
- 視点キャラがまだ言語化できていないものを書くときは「気がした」「ような」で保留する

## ベンチマーク2：内心独白がキャラの性格を示す ―― コメディの「内心ツッコミ」

**出典**: 第八話「鉄板ナポリタン事件」（蓮司のナポリタン提供シーン）

**シーン**: コーヒー専門店のはずなのに、常連の男子高校生・蓮司の押しに負けて店長の柊一が鉄板ナポリタンを作る羽目になる。

**◎ベンチマーク**:

```
　柊一は無表情でカウンターの中に戻っていた。布を取ってまた、カップを磨き始めている。
（なぜ、俺はフライパンを振っているんだ）
（コーヒー専門店だぞ、ここは）
　しかし、布を持った手がふっと止まった。
　蓮司が二杯目の大盛りを「もう一回お願いしますっ」と頭を下げて頬を紅潮させながら鉄板に向き直っている。三杯目を頼む頃には、もう何も話さず、ひたすら麺と卵を口に運んでいた。
　柊一の口元がほんの一ミリだけ、緩んだ。すぐに引き締めた。引き締めたつもりだったが、布を握る手の圧がいつもより、ほんのわずかだけ抜けている。
```

**なぜこのリズム・密度が良いか**:

1. **独白が「解説」ではなく「人格」を示す**: 「（なぜ、俺はフライパンを振っているんだ）」は出来事の解説ではない。柊一というキャラの「コーヒー以外を作る自分への戸惑い」そのもの。読み終わったあと、読者の中に残るのは出来事の情報ではなくキャラの性格
2. **独白が短く、続かない**: 二行で終わる。続けて長い解釈を入れない。「コーヒー専門店だぞ、ここは」で止めて、すぐに地の文に戻る
3. **出来事と解説の比率が出来事優位**: 7文中、独白は2文。残りは身体動作・周辺描写・口元の変化など、身体的事象。`style-rules.md` A-7 の「事象1：解説1」比率を守っている
4. **動作で感情を見せる（Show, Don't Tell）**: 「口元がほんの一ミリだけ、緩んだ」「布を握る手の圧がいつもより、ほんのわずかだけ抜けている」。「嬉しそう」と書かずに嬉しさを描く
5. **テンポで動く**: ナポリタンを食べる蓮司の勢いと柊一の小さな反応が同じ画面に並んで、コメディの呼吸が生まれる。独白を増やすと止まってしまう

**学べる原則**:

- 内心独白は「読者への解説」ではなく「キャラの性格を見せる一行」として使う
- コメディシーンほど独白は短く、地の文と動作で動かす
- 感情変化は「口元」「手の圧」「指の角度」など、最小単位の身体描写で見せる
- 一文が長くなりかけたら、二文に切る（「すぐに引き締めた。引き締めたつもりだったが、〜」）

## ベンチマーク3：冷静な外側の観察 ―― 独白が人物の性格そのものを示す

**出典**: 第九話「全員片想い」（柳瀬副社長が店の前を通り過ぎる段）

**シーン**: 千影の所属事務所の柳瀬副社長が、店内の千影の様子を確認するために店の前の歩道を通り過ぎる。視点は柳瀬。

**◎ベンチマーク**:

```
　店の前の歩道を黒のテーラードジャケットを羽織った背の高い女がゆっくりとした歩調で通り過ぎた。
　柳瀬静香は足を止めない。けれど顔だけ、ほんの一瞬、マンハッタンの古びたファサードの方に向けて窓越しに店内を目だけですっと見た。
　窓越しに見えた構図——カウンターの中に柊一と千影が並び立っている。柊一が湯のポットを傾けて千影がトレイを受け取ろうとしている、そのほんの一拍。
　柳瀬の足は止まらない。視線は二秒、三秒。
　ふっと視線が店内から外れた。柳瀬は何事もない歩調で店の前を通り過ぎていった。
（……へえ）
（男装のバイト、ね）
（真白千影）
（——真白家のお嬢さんが、あの小さな喫茶店のカウンターで）
（あの静かそうなマスターの隣で）
（ずいぶん、自然に立ってるのね）
（……芝居で作った立ち姿じゃ、ない）
（あれは、素の立ち姿よ）
　柳瀬は街路樹の影に入った。
（……報告すべきか）
（黙っておくべきか）
（鷹宮が知ったら、確実に首を突っ込みに来る）
　柳瀬はヒールの音をいつもの歩調のまま、角の手前で滑らかに右へ折った。歩道から姿が消えた。
```

**なぜこのリズム・密度が良いか**:

1. **独白が「解説」ではなく「観察者の性格」を示す**: 柳瀬の独白群は、出来事の解説ではない。「（……へえ）」「（ずいぶん、自然に立ってるのね）」「（……芝居で作った立ち姿じゃ、ない）」「（あれは、素の立ち姿よ）」——これらは柳瀬という人物の「冷たい観察眼」「業界人の俯瞰」「即時の判定癖」を示している。柳瀬の独白を全部消しても出来事は伝わるが、柳瀬の「人物」は消える
2. **独白が連続するが解釈で詰まらない**: 7行連続の独白だが、各行が一つの観察・一つの判定。連続しているのに過密に感じない。`style-rules.md` F-2 の「3行以上の連続独白は身体動作で分割」を破っているが、ここでは破ることが効果になっている。**ルールを破る判断は、その独白がキャラ造形そのものになっている場合のみ**
3. **動作の精度が高い**: 「足を止めない」「顔だけ、ほんの一瞬」「視線は二秒、三秒」「ふっと視線が店内から外れた」「いつもの歩調のまま、角の手前で滑らかに右へ折った」——すべて「止まらない」「変えない」動作。柳瀬の冷静さが、行動の機微で描かれる
4. **最後の一文の体言止め的処理**: 「歩道から姿が消えた」。柳瀬の退場が一行で終わる。引きずらない。説明しない
5. **視点キャラが事件の当事者ではない**: 当事者の独白（千影視点）なら動揺・葛藤の独白になるが、観察者視点なら情報整理・判定の独白になる。シーンの種類（観察 vs 当事）で独白の質を変えている

**学べる原則**:

- 独白は「シーンの説明」ではなく「視点キャラの性格そのもの」を示す手段として使う
- 観察者視点のシーンは独白を「観察記録」「判定」「次の打ち手の検討」で構成する。当事者の独白とは質が違う
- 動作描写は「変えない・止めない・揃える」を選ぶことで、キャラの冷静さ・余裕・支配感を表現できる
- 退場や場面の終わりは、引きずらず一行で済ませる

## 三つのベンチマークから抽出される共通原則

| 原則 | ベンチマーク1 | ベンチマーク2 | ベンチマーク3 |
|---|---|---|---|
| 独白の役割 | 余韻で止める | キャラの性格を一行で示す | 観察者の性格を構造で示す |
| 出来事：解説の比率 | 解説ゼロ（最後の一文） | 出来事優位 | 独白優位だが各行が独立した判定 |
| 動作の使い方 | 触感の対比だけ | 最小単位の身体描写で感情変化 | 「変えない」動作で冷静を見せる |
| 終わり方 | 「気がした」で保留 | 動作と圧の変化で締める | 一行で退場 |

**全ベンチマーク共通**:

- 独白を「読者に説明する」ためには使わない
- 触感・五感の事象は、最後の一文で止めるか、対比だけを残す
- 一文が長くなりかけたら二文に切る
- 動作描写は「最小単位の変化」を選ぶ（「ほんの一ミリ」「半拍」「ほんのわずか」）

**全ベンチマーク共通の「やっていないこと」**:

- テーマワード（「嘘」「正直」「演技」）を視点キャラ本人に貼り直させていない
- 反射的間投詞（（あ）（やばい））を連発していない
- 「読者に説明するための一文」を入れていない
- 「もう一人の登場人物が考えていること」を地の文で書いていない（POV固定）
