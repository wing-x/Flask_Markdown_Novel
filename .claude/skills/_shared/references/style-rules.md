# 汎用スタイルルール

**このファイルの目的******: 日本語 Web 小説の執筆時・チェック時に適用する定量・定性ルールを具体例付きで列挙する。抽象指示 (「自然に書く」「キャラらしく」) は書かない。****

参照元: `novel-write` (生成時)、`novel-check` (事後チェック時)、`novel-fix` (修正時)

---

## A. 内心モノローグのルール

### A-1. 1つの内心モノローグは原則120字以下

超える場合は身体動作や他キャラの介入で分割する。地の文で挟むか、ダッシュや三点リーダで切って別の塊にする。

**◎良い例**:
```
（……またこの笑い方だ）
 柊一は豆の袋を棚に戻す。指先が少し震えた。
（——楽だが、少し寂しい）
```

**✗悪い例**:
```
（またこの笑い方だ。一年前ならこの笑い方が出るたびに俺は何かをすり替えていた。「場の空気を読め」とか、「腕が細い」とか。そういうのを全部言い訳にしていた。でも今はもう何もすり替えなくていい。それが、楽だ。楽だが、少し寂しい。なんでだろう。わからない）
```
→ 165字。長すぎて読者の息が続かない。独白ではなく説明になっている。

---

### A-2. キャラ自身にテーマや設定を解説させない

内心は「思考」であり、解説ナレーションではない。読者への説明を内心に混ぜ込まない。

**◎良い例**:
```
（……またこの笑い方だ。——楽だが、少し寂しい）
```

**✗悪い例**:
```
（一年前は、この笑い方が出るたびに俺は何かをすり替えていた。「場の空気を読め」とか、「腕が細い」とか。今は——もう何もすり替えなくていい。それが、楽だ。楽だが、少し寂しい）
```
→ キャラが自分の過去を読者に向けて解説している。

---

### A-3. 具体的な数字・年齢・年数を内心で数えない

数字は地の文や台詞に任せる。内心で数えると「状況説明を自分にしている」不自然さが出る。

**✗悪い例**:
```
（26年間一度もやったことないから何にもわからない）
```

**◎良い例**:
```
（何が正解かわからない）
```

---

### A-4. メニュー名・作品名・項目を羅列しない

内心で列挙すると「作者が情報を並べたい」意図が透ける。1つか2つに絞る、または象徴で済ませる。

**✗悪い例**:
```
（ナポリタン、オムライス、カレー、ケーキ、コラボ、チョコドリンク。……この店のメニュー表、もう原形とどめてないですよね）
```

**◎良い例**:
```
（6回目。もう数えてる自分がいる）
```

---

### A-5. 感情は説明より反復で表現する

「好きだ」「でもダメだ」「分かってる」と順に説明するより、同じ語の反復・半ば・ダッシュで情感を作る。

**◎良い例**:
```
（なんで泣いてるの。……分かってるくせに。——ばかみたい）
```

**✗悪い例**:
```
（なんで泣いてるの私。なんで。分かってるのに分かってないの。好きだって分かった。でもダメだって分かってる。分かってるのに止まらない。感情が。涙が。全部がぐちゃぐちゃで——柄にもない）
```
→ 感情の「理由の説明」を詰め込んでいる。読者は理由を既に察している。

---

### A-6. 内心モノローグにキャラ名ラベルを付けない

「キャラ名の内心：（...）」はプロット設計用の帰属記法であり、小説本文では使わない。本文の内心モノローグは括弧のみで表記し、帰属は前後の地の文（直前の動作・直前の台詞の話者）で示す。POVが切り替わる場面でも、身体動作や視点指示の一行を挟むことで帰属を示す。

**✗悪い例**:
```
「信じてたのに。……どうして」

　千影の内心：（硬い）

　マスターの内心：（……何だ、今の）
```
→ ト書き・脚本形式の混入。小説本文では帰属ラベルを使わない。

**◎良い例**:
```
「信じてたのに。……どうして」

（硬い）

　千影がふっと笑った。素の、笑い方だった。

　カップを磨いていた柊一の手が、止まった。

（……何だ、今の）
```
→ 身体動作でPOVの切り替わりを示し、その後の内心が柊一のものであることを文脈で示す。

---

### A-7. 出来事と解説を等間隔に並べない（情報密度のリズム）

身体的・物理的な「出来事」（触感・接触・動作・五感）と、それを受けた「解説」（内心・解釈・要約）を等間隔で交互配置すると、読者が出来事の余韻を受け取る前に解釈が押し寄せ、情報密度のリズムが単調になる。  
文のリズムではなく **情報密度のリズム** の問題。

**原則**:

- 出来事の直後に解説を置く場合、解説は出来事より短くする（事象1：解説1までを目安）
- 一段落あたり「出来事系：解説系」の文比率が 1:3 を超えたら、解説側を削る
- 物理的接触・五感的描写の直後は「短い余韻」で止め、長い解釈モノローグを置かない。**最後の一文で止めるべきだった箇所を、その前に全部解説してしまわないこと**

**✗悪い例**（出来事→解説→出来事→解説の等間隔）:
```
　柊一が千影の手首を冷水に浸す。
（細い。男にしては——いや、栄養が）
（明日、賄いでも出すか）
　千影の手首が震える。
（マスターの手が）
（私の手首をつかんでる）
（冷たい水と温かい指）
（心臓、うるさいな）
```
→ 接触一つに対し二人分の長い解釈が並ぶ。触感の余韻が消える。語り手が先に受け取って、噛み砕いて、結論まで添えて差し出している。

**◎良い例**（出来事→短い余韻で止める）:
```
　柊一が千影の手首を冷水に浸す。
　水の冷たさと指の温かさの差だけが、まだ皮膚の上に残っている気がした。
```
→ 解釈を読者に渡す。最後の一文で止めて、次の段落へ。

**チェック手順**: 段落内の「身体動作・触感・物音・視覚的事象を描く文」と「内心括弧書き・地の文の解釈文」の数を数える。3〜5文の段落で内心が出来事の3倍を超える、または5文以上の段落で内心が出来事と等量を超える箇所は要削減。

---

### A-8. 反射的間投詞の頻度を制限する

「（あ）」「（やばい）」「（待って）」「（え）」「（えっ）」「（——え）」「（あっ）」のような単独の反射的間投詞は、心が動くたびにデフォルト反応として挿入されがちだが、頻発すると「動揺」がインフレを起こし、読者が動揺を受け取らなくなる。

人間が本当に動揺したとき、こういう言葉はむしろ思考から消える。動作と身体だけで動揺は描ける。「指がカップの上で止まった」だけで動揺は届く。「（あ）」と心の中で発音させる必要はない。

**原則**:

- 単独括弧書き間投詞の合計上限は **1章3回まで**（プロジェクトの `rules.md` 「反射的間投詞の上限」セクションで上書き可能）
- 超過分は以下のいずれかに置換する:
  - 動作描写への置換: 「（あ）」→「指がカップの上で止まった」
  - 身体反応への置換: 「（やばい）」→「血が指先から引いた」
  - 完全削除（前後文脈で意味が通る場合）

**✗悪い例**:
```
（あ）
（やばい）
（待って、これ——）
（え）
（あっ）
```
→ 反射音が連続。動揺がインフレを起こし、どれも刺さらない。

**◎良い例**（動作で動揺を見せる）:
```
　指がカップの上で止まった。
　磨きかけのグラスが、棚の縁で半拍だけ揺れた。
　息を吐くタイミングを、一度見失った。
```
→ 一文も間投詞を使わずに、動揺の段階を描ける。

**チェック手順**: 章内を `（あ）` `（やばい）` `（待って）` `（え）` `（えっ）` `（——え）` `（あっ）` でgrepし、単独行で完結している間投詞の総数を数える。3個を超えたら超過分を上記のいずれかに置換する。

**例外**: コメディシーンのツッコミ的な「（あ）」「（えっ）」は許容範囲を広げてよいが、シリアスシーンで使うと反射的間投詞として扱う。

## B. 台詞のルール

### B-1. 一人の話者の台詞が80字を超えたら、相手の相槌や反応で分割する

長大な独白台詞は小説として不自然。口で読んで息が続かない台詞は書かない。

**◎良い例**:
```
「俺はもう、ずっと先生が大好きでした」
 千影が息を呑む。
「……差し入れも、プレゼントも、全部口実でした」
```

**✗悪い例**:
```
「俺はもう、ずっと先生が大好きでした！ 好きじゃなかったらあんなに差し入れもプレゼントもしないですよ！ 全部、全部先生と会って話すための口実です！」
```
→ 1発話で70字超 + 勢いで別文を3つ繋げている。

---

### B-2. 寡黙系キャラは「……」を多用し、必要最低限しか喋らない

「喋らないこと」自体がキャラ付けになる。無理に言葉を出させない。

**◎良い例**:
```
「……うん」
「……どうかな」
「……別に」
```

---

### B-3. 重要な台詞ほど短く決める

告白・決別・決意のような「決定的台詞」に説明や言い訳を足さない。短い方がインパクトが残る。

**◎良い例**:
```
律「俺はもう、ずっと先生が大好きでした」
```

**✗悪い例**:
```
律「俺はもう、ずっと先生が大好きでした！ 好きじゃなかったらあんなに差し入れもプレゼントもしないですよ！ 全部、全部先生と会って話すための口実です！」
```

---

## C. 地の文のルール

### C-1. 感情を「説明」する前に「身体動作」で見せる

Show, Don't Tell の最小単位。「動揺した」と書くのではなく、動揺が現れた身体反応を書く。

**✗悪い例**:
```
柊一は動揺した。
```

**◎良い例**:
```
柊一の手から豆の袋が落ちそうになる。慌てて掴み直す。
```

---

### C-2. 不自然に独創的な比喩を避ける

普通の言葉で済むなら普通に書く。凝った比喩は読者の目を止める「引っかかり」になる。

**✗悪い例**:
```
千影の笑みは、ハートというより歪んだ豆になる。
```

**◎良い例**:
```
千影の笑みは、崩れたハートになる。
```

---

### C-3. 「説明的な地の文」と「キャラの視点から見た地の文」を混同しない

視点人物の知らない情報を地の文で書かない。視点人物の気づき・感覚・評価を通して描写する。

**✗悪い例**:
```
（柊一視点の章で）
千影は幼い頃から人前で笑うのが苦手だった。それは両親の離婚が原因で……
```
→ 視点人物が知らない他キャラの経歴を地の文で解説。

**◎良い例**:
```
（柊一視点の章で）
 千影の笑い方は、なぜか少しぎこちない。柊一にはその理由は分からない。ただ、慣れない動作を繰り返しているような、そんな感じがするだけだ。
```

---

### C-4. 読点（、）を過剰に打たない

**原則**: 地の文の1文に打つ読点は、原則として2個まで。3個以上になったら文を分けるか、不要な読点を削る。読点を増やすと「ためらいがち」「詩的」「しみじみ感」が出るが、やりすぎると文章が細切れになり、読者のリズムを壊す。

**特に多い過剰パターン（全て削る）**:

1. **主語直後の余分な読点**: 主語＋述語が短く続くなら、主語直後の読点は不要
   - ✗「彩音は、ブレザーの袖に腕を通した」
   - ⭕「彩音はブレザーの袖に腕を通した」
   - ※「柊一は、カップを磨きながら、ふと外を見た」のように従属節を挟むなら主語直後の読点は許容

2. **副詞＋形容詞/動詞の間の読点**: 副詞は後続の語と一体で読ませる
   - ✗「ほんの少しだけ、柔らかい」「じっと、見ていた」「ゆっくりと、消えていく」
   - ⭕「ほんの少しだけ柔らかい」「じっと見ていた」「ゆっくりと消えていく」

3. **オノマトペ＋格助詞「と」の間の読点**: 擬音・擬態語と「と」の間に読点を挟まない
   - ✗「ぱっ、と明るくなった」「ふっ、と笑った」「びくっ、と引っ込んだ」「ぎゅっ、と握った」
   - ⭕「ぱっと明るくなった」「ふっと笑った」「びくっと引っ込んだ」「ぎゅっと握った」

4. **「の、の」の二重連体**: 連続する「の」の間に読点を挟まない
   - ✗「カウンターの中の、男のバイトの姿」
   - ⭕「カウンターの中の男のバイトの姿」

5. **同一節内の細切れ分割**: 短い句を3個以上の読点で分けない
   - ✗「千影の視線が、ほんの一瞬だけ、マスターの手元に、留まった」（読点4個）
   - ⭕「千影の視線がほんの一瞬だけ、マスターの手元に留まった」（読点1個）
   - ✗「律は、自分の部屋に戻って、背中をドアにつけて、ずるずると、しゃがみ込んだ」（読点4個）
   - ⭕「律は自分の部屋に戻って、背中をドアにつけて、ずるずるとしゃがみ込んだ」（読点2個）

6. **「〜は、〜が、〜を、」の三連読点**: 助詞ごとに読点を打たない
   - ✗「律は、彩音の顔を、じっと、見た」
   - ⭕「律は彩音の顔を、じっと見た」

**読点を残してよい場面（削ってはいけない）**:

- **ダッシュ「——」の前後の余韻**: `——彼女は、笑っていた。` のような劇的な間は保持
- **強調のための単語分離**: `近い。近すぎる。` のような意図的な短文はそのまま
- **台詞（「」）と内心（（））の中**: キャラクターの声のリズムは作者の地の文ルールと別枠。内心の「、」は削らない
- **逆接・理由節の区切り**: 「〜けれど、〜」「〜から、〜」のような節の境界は残す
- **長い主語や修飾節の後**: 「カウンターの端で静かにコーヒーを飲んでいた律が、ふと顔を上げた」のように主語が長ければ直後の読点は必要

**チェック手順**: 地の文を書いたら、1文ごとに読点の数を数える。3個以上ある文は「本当に全部必要か」を見直し、上記1〜6のパターンに該当するものを削る。

## D. キャラクターの一貫性ルール

### D-1. 一人称は明確に規定する

「僕」「俺」「私」「うち」「あたし」等、キャラごとに固定する。感情の揺れで一時的に変化させる場合は**必ず事前にルール化**する。

**例 (ルール化された揺れ)**:
- 律は普段「僕」。感情が昂ったときだけ「俺」が漏れる。
- ひなたは普段「うち」。先生の前でだけ「私」になる。

**✗やってはいけないこと**:
- ルールなく地の文で「僕」と「俺」が混在
- 章ごとにブレる

---

### D-2. 呼称は明確に規定する

誰が誰をどう呼ぶかを表で管理し、地の文・台詞で一貫させる。

**例**:
| 話者 → 対象 | 呼称 |
|---|---|
| 柊一 → 千影 | 「マスター」 (台詞)、「千影さん」 (内心) |
| 千影 → 柊一 | 「柊一くん」 |
| 律 → 先生 | 「先生」 (台詞)、「先生」 (内心) |

---

### D-3. 口癖・決め台詞は使用回数を制限する

多用するとインパクトが消える。1章に1〜2回までに抑え、重要な場面で使う。「心臓が跳ねた」「息を呑む」等の身体描写も同じ部内で3回以上使わない。

---

## E. 文末表現のルール

### E-1. 同じ文末を4文以上連続させない

「〜た」「〜ていた」「〜だった」等の過去形系が連続すると、文章が単調なリズムで進み、全てが「遠景から眺めている」ような距離感になる。4文目には必ず別の文末を入れる。

**✗悪い例** (5文連続「〜た/ていた」):
```
磨いていた。
座っていた。
預けていた。
傾いていた。
開けていなかった。
```

**◎良い例** (文末を散らす):
```
磨いていた。
座っている。高峰の隣——例の男だ。
こめかみを預けたまま動かない。
男の肩がわずかに傾いていた。
万年筆の蓋は、閉じたまま。
```

---

### E-2. 1章の文末分布で過去形系を75%以下に抑える

文末のバリエーション配分の目安:

| 文末タイプ | 目標比率 | 効果 |
|-----------|---------|------|
| 過去完了形（〜た） | 40〜50% | 物語の基本トーン |
| 継続過去（〜ていた） | 10〜15% | 状態描写（多用厳禁） |
| 現在形（〜る/〜いる） | 10〜15% | 臨場感、緊張感 |
| 体言止め | 8〜12% | リズムの加速、印象の強調 |
| 疑問形（〜か/〜だろう） | 3〜5% | 読者への問いかけ、内省 |
| 省略文・倒置法 | 3〜5% | 意外性、余韻 |
| 否定形（〜ない/〜なかった） | 5〜10% | 緊張、不在の描写 |

**特に「〜ていた」の過剰に注意**。「座っていた」「磨いていた」「預けていた」と続くと全文が状態描写になり、物語が動いていないように感じる。「〜ていた」は1段落に2回までを目安とする。

---

### E-3. 緊張場面では現在形に切り替える

クライマックス（告白・正体バレ・対決等）では、過去形から現在形に切り替えることで臨場感が跳ね上がる。

**◎良い例** (現在形でクライマックス):
```
　柊一の手が止まる。カップが棚の縁で揺れる。
　千影の目が、真っ直ぐこちらを見ている。
　息ができない。
「——お前のことが、好きだ」
　声が出た。自分の声だった。
```

**✗悪い例** (クライマックスも過去形のまま):
```
　柊一の手が止まった。カップが棚の縁で揺れた。
　千影の目が真っ直ぐこちらを見ていた。
　息ができなかった。
「——お前のことが、好きだ」
　声が出た。自分の声だった。
```
→ 過去形のまま書くと「回想」のように読め、没入感が落ちる。

---

### E-4. 体言止めは「強調したい一瞬」に使う

体言止めは読者の目を止める効果がある。乱用すると効果が消えるが、全く使わないと文章が単調になる。1章に5〜10回が目安。

**◎効果的な使い方**:
```
　ドアベルの音。
　振り向いた先に——千影がいた。
```

```
　カウンターの上、白い湯気。二つのカップ。沈黙。
```

---

## F. 内心モノローグの頻度制限

### F-1. 1章あたりの（ ）は15個以下

A-1（1ブロック120字以下）は個々のモノローグの長さを制限するが、頻度も同様に重要。（ ）が30個以上ある章は「読者が自分で感じ取る余地を奪っている」状態。

| 場面タイプ | （ ）の目安 |
|-----------|-----------|
| 日常シーン | 5〜8個 |
| 感情が動くシーン | 8〜12個 |
| クライマックス | 3〜5個（行動で見せる） |
| コメディシーン | 5〜10個（ツッコミ用途OK） |

**判定基準**: 章を書き終えたら（ ）の数を数える。15個を超えている場合、以下の基準で削る:
- 「この（ ）がないと読者が理解できない」→ 残す
- 「読者が行動描写から察せる」→ 削って行動描写に置き換える
- 「（……変なの）（……わからない）」系の保留型 → 原則削除

---

### F-2. 3行以上の連続（ ）は身体動作で分割する（必須）

`monologue-guidelines.md` セクション2の技法を定量ルールとして昇格:

**（ ）が3行連続したら、必ず次の行は身体動作・地の文にする。** 4行以上の連続（ ）は禁止。

**✗禁止パターン**:
```
（……来た）
（学校の子だ）
（……落ち着け日野彩音）
（私はここの常連）
（律くんは学生パスの客）
（それだけ）
（それだけのことよ）
```
→ 7行連続。キャラが宙に浮いて、読者は映像を見失う。

**◎修正例**:
```
（……来た。学校の子だ）
　彩音はカップの縁を下唇に当てた。指先に力が入る。
（私はここの常連。律くんは学生パスの客。それだけのこと）
```
→ 3個に圧縮し、身体動作を挟んだ。

## G. 演出表現の全体予算

### G-1. 特定の演出手法は「全編」で使用回数を制限する

印象的な演出は「最も効果的な1回」に全てを賭けることで威力が出る。使い回すと効果が摩耗する。

| 演出手法 | 全編上限 | 1部あたり上限 | 代替表現 |
|---------|---------|-------------|---------|
| 「手が止まった/止まる」 | 5回 | 2回 | 手が加速する、握り込む、指先が逸れる、一拍遅れる |
| 「心臓が跳ねた/鳴った」 | キャラ各2回 | キャラ各1回 | character.md の身体反応パターンを使う |
| 「耳が赤くなった」 | キャラ各2回 | キャラ各1回 | 首筋が熱い、指先が冷たくなる、声が上ずる |
| 「息を呑んだ」 | 5回 | 2回 | 呼吸が浅くなる、喉が詰まる、肺の底が重い |
| 「〇〇は気づいていない/知らない」 | 0回 | 0回 | 行動描写のみで示す（forbidden-patterns.md #22） |

---

### G-2. 背景動作の反復を避ける

特定のキャラの「デフォルト動作」（カップを磨く、布巾を畳む等）は背景として便利だが、毎話毎場面で使うと意味が消える。

- 同一の背景動作は**1部あたり3回まで**
- 「今日はその動作をしていない」ことで変化を示す方が効果的
- 代替の背景動作リストを用意する（豆を選別する、棚を整理する、メニューを書き直す、窓を拭く等）

---

### G-3. 場面転換の手法を散らす

ダッシュ「——」による場面転換（「——翌日。マンハッタン。午後。」等）は1章2回まで。3回目以降は別の手法を使う。

| 転換手法 | 例 | 効果 |
|---------|---|------|
| 空行のみ（2行） | （空行）新しい場面の描写から始める | 最もシンプル。読者の想像に委ねる |
| 音で繋ぐ | 「ドアベルが鳴った」→ 新場面 | 聴覚的な橋渡し |
| 同一動作の反復 | 前場面「コーヒーを飲んだ」→ 新場面「コーヒーを飲み干した」 | 時間経過を暗示 |
| 対比で繋ぐ | 前場面「朝の光」→ 新場面「夕日が窓を染めていた」 | 時間の跳躍を印象的に |
| カットイン | 場面の途中で突然新場面の描写が始まる | 映画的、テンポが良い |
| 人物の移動 | 「千影は店を出た。商店街を抜け——」→ 新場面 | 空間的な連続性 |

## H. 五感バランスのルール

### H-1. 1シーンに最低1つの非視覚描写を入れる

人間は視覚以外の感覚（聴覚・嗅覚・触覚・味覚・温度感覚）でも空間を認識している。視覚だけで場面を描写すると「映像の説明文」になり、読者の没入感が薄れる。

**✗悪い例** (全て視覚):
```
　店内には木製のカウンターがあり、棚にはコーヒー豆の袋が並んでいた。壁には手書きのメニューが掛かっている。窓から夕日が差し込んでいた。
```

**◎良い例** (複数の感覚):
```
　エスプレッソマシンの蒸気音が低く響いている。カウンターに手を置くと、磨き込まれた木の冷たさが指先に伝わった。焙煎したての豆の香りが、店の奥から漂ってくる。
```

---

### H-2. 場所ごとの「五感プロファイル」を活用する

`worldbuilding.md` に場所ごとの五感プロファイル（音・匂い・温度/触感・光）が定義されている場合、その場所のシーンを書く際に必ず参照する。ただし全属性を毎回列挙する必要はない。1シーンにつき1〜2の非視覚感覚をさりげなく織り込む。

**原則**:
- **初登場の場所**: 2つ以上の非視覚描写で場の空気を確立する
- **繰り返し登場する場所**: 毎回同じ描写を繰り返さない。「いつもと違う音」「今日は匂いが薄い」など、変化で鮮度を保つ
- **感情と連動**: キャラの感情状態によって、同じ場所の感覚描写が変わる（緊張時は音が大きく聞こえる、幸福時は香りに気づく等）

---

### H-3. 感覚描写は地の文に自然に溶かす

感覚描写を「説明」として追加するのではなく、キャラクターの動作や思考の中に溶け込ませる。

**✗悪い例** (説明的):
```
　店内にはコーヒーの匂いが漂っていた。BGMはジャズだった。カウンターは冷たかった。
```

**◎良い例** (動作に溶かす):
```
　柊一がカップを置いた。カウンターの冷たさが、指の腹から肘まで伝わる。奥のスピーカーからピアノトリオの演奏が流れている——今日はビル・エヴァンス。
```
