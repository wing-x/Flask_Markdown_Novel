# 整合性チェックリスト (汎用)

**このファイルの目的**: 執筆後の整合性チェックで順に検証すべき項目の汎用版。`novel-check` / `novel-check-plot` / `novel-fix` が本文・プロット・修正時に参照する。作品固有の追加項目は `projects/{作品名}/check_notes.md` に置き、合成して使う。

参照元: `novel-check` (5観点チェック時)、`novel-check-plot` (プロット観点チェック時)、`novel-fix` (修正前の再確認時)

---

## 【キャラクター整合性】

- [ ] 一人称は設定通りか (`character.md` に規定されたもの)
- [ ] 呼称は設定通りか (誰が誰をどう呼ぶかの表と照合)
- [ ] 口調 (敬語 / タメ口 / 語尾 / 方言) は設定通りか
- [ ] **その時点でキャラが知っている情報と矛盾しないか** (`timeline.md` の「キャラクター知識・認知の変遷」と照合)
- [ ] キャラの身体的特徴・癖は維持されているか (髪色・目の色・身長・利き手等)
- [ ] 感情の段階的変化が前話と矛盾しないか (急激な変貌は設定やプロット側の転換点と対応しているか)
- [ ] 行動が `character.md` の性格・価値観・能力から自然に導かれているか
- [ ] 心理描写 (感情反応・恐怖の対象・怒りの沸点) が背景・トラウマ設定と一致しているか
- [ ] 内心独白の語彙・思考の癖がキャラの知性・教養・性格と整合しているか

---

## 【時系列・設定整合性】

- [ ] 章番号・時期・季節が矛盾しないか
- [ ] キャラの年齢・経歴の数字が矛盾しないか (「26歳」と「大学4年」の衝突等)
- [ ] 前話からの経過時間が自然か (一晩 / 数日 / 数週間のいずれか明示されているか)
- [ ] 世界観ルール (作品固有の設定) に反していないか (魔法体系・社会制度・特殊能力等)
- [ ] 伏線の設置順と回収順が整合しているか (設置前に回収していないか)
- [ ] 固有名詞の表記揺れはないか (「千影」と「ちかげ」の混在等)
- [ ] 場所の地理関係が矛盾しないか (A→Bに徒歩5分と書いた後、別章で車で30分等)

---

## 【文体整合性】

- [ ] 視点の切り替えは明示的か (曖昧な視点移動はないか)
- [ ] 1シーン1視点を守っているか (段落内でのザッピングがないか)
- [ ] 文体のトーンが前話と一致しているか (急に重くなる / 軽くなる等の崩れ)
- [ ] 敬語 / 常体の混在はないか (地の文の文体統一)
- [ ] 地の文の時制は統一されているか (現在形 / 過去形の無意識な混在)
- [ ] 一人称視点と三人称視点を章内で混ぜていないか

---

## 【執筆精度 (定量ルール)】

- [ ] **内心モノローグで 120字超のものはあるか** (あれば行番号を列挙し、分割案を提示)
- [ ] **一人の台詞で 80字超の独白はあるか** (あれば行番号を列挙し、分割案を提示)
- [ ] キャラ設定の自己解説モノローグはないか (`forbidden-patterns.md` 1〜3番)
- [ ] 説明的な羅列 (メニュー・年数・年齢の数え上げ) はないか (`style-rules.md` A-3, A-4)
- [ ] 不自然に独創的な比喩はないか (`style-rules.md` C-2)
- [ ] 「〜のだった」「〜なのであった」調の古風な締めはないか
- [ ] 同じ締め表現が直前の章と重複していないか
- [ ] 同一の身体描写 (「心臓が跳ねた」等) を同部内で3回以上使っていないか
- [ ] 副詞 (「とても」「非常に」「本当に」「まさに」) の連発はないか

---

## 【視点・POVチェック】

- [ ] 視点人物以外のキャラクターの内心を括弧 `（）` で記述していないか
- [ ] 「○○は〜と思った」「○○は〜を感じた」等で視点人物以外の内面を断定していないか
- [ ] 視点人物が知らない情報を地の文で解説していないか
- [ ] 視点人物が知らない他キャラの過去・経歴を地の文に紛れ込ませていないか

---

## 【メタ混入チェック】

- [ ] 話数番号 (「第○話」「第○章」) が本文中に混入していないか (章タイトル行は除く)
- [ ] 「読者」という語が本文中に混入していないか (章タイトルや台詞内の正当な使用を除く)
- [ ] プロットのセクション名 (「読者への効果」「伏線」「シーン1」等) が混入していないか
- [ ] 設定メモの語句 (「character設定」「worldbuilding」「プロット」等) が混入していないか
- [ ] 作者の声 (「ここで読者は驚くだろう」等) が混入していないか
- [ ] 算用数字 (0-9) が本文中に使われていないか (看板・POP等の描写内を除く)

---

## 【引き・章末】

- [ ] プロットの「引き:」フィールドで指定された引きの種類が実現されているか (章末・エピローグを除く)
- [ ] 章の最後の1〜3行に引きの核となる要素が配置されているか
- [ ] 日常の延長でそのまま終わっていないか (最終章を除く)
- [ ] 全てが解決してすっきり終わっていないか (最終章を除く)

---

## 【伏線整合】

- [ ] プロットで設置予定の伏線が本文に書かれているか
- [ ] プロットで回収予定の伏線が本文で回収されているか
- [ ] 伏線の設置順と回収順が時系列的に正しいか
- [ ] 伏線の回収をキャラに気づかせて解説させていないか (`forbidden-patterns.md` 14番)

---

## 使い方

1. 章単位のチェック: 全項目を順に検証し、問題箇所を行番号付きで列挙する
2. 部単位のチェック: 同じ部内の章をまたいだ整合性を追加で検証する
3. 全体チェック: 全章読み込みで横断的に検証する
4. 問題の深刻度表示: 🔴 要修正 / 🟡 要判断 / 🟢 問題なし

報告形式は各スキル (`novel-check` / `novel-check-plot`) の出力フォーマットに従う。
