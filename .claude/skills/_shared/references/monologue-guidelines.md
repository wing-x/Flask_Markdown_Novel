# 内心モノローグ ガイドライン

**このファイルの目的**: 内心モノローグを書く/チェックするときの具体的な指針。定量ルール (120字上限) は `style-rules.md` A節を、禁止パターンは `forbidden-patterns.md` 1〜6 を参照。ここでは「どう書くか」の技法を扱う。

参照元: `novel-write` (内心を含む章を書くとき)、`novel-check` (内心のチェック時)

---

## 1. 「長い独白」と「短い断片の連続」の使い分け

| 場面 | 推奨 | 理由 |
|---|---|---|
| 感情が動いた瞬間 | 短い断片 | 読者に直接刺さる。息継ぎの隙に余韻が生まれる |
| 状況を整理する場面 | 短い断片 + 身体動作 | 長い独白で整理させない (説明臭くなる) |
| 過去の回想に入る | 長めの独白も可 | ただし120字で一度区切り、地の文を挟む |
| 決断の瞬間 | 1〜2行の短文 | 長くすると決断の重みが薄れる |

**原則**: 迷ったら短い断片。長い独白は「本当に必要なとき」だけ。

---

## 2. 身体動作との組み合わせ方

内心は単独で立たせず、身体動作と交互に配置する。読者の視覚情報と内面情報を交互に流し込むことで、情景が立体になる。

**◎良い例**:
```
（……またこの笑い方だ）
 柊一は豆の袋を棚に戻す。指先が少し震えた。
（楽だが、少し寂しい）
```

**✗悪い例** (内心が連続して身体がない):
```
（またこの笑い方だ）
（楽だが、少し寂しい）
（でも、いつまで楽でいられるかな）
（わからない）
```
→ キャラが宙に浮いて見える。

## 3. ダッシュ (——) と三点リーダ (……) の使い方

| 記号 | 用途 | 例 |
|---|---|---|
| `——` (ダッシュ2つ) | 思考の転換・言い直し・結論への飛躍 | `（楽だ。——楽だが、少し寂しい）` |
| `……` (三点リーダ) | 言いよどみ・感情の揺らぎ・沈黙 | `（……分かってるくせに）` |

**組み合わせ例**:
```
（……またこの笑い方だ。——楽だが、少し寂しい）
```

**注意**:
- 三点リーダは**2つ連結** (`……`) が基本。1つ (`…`) や3つ (`………`) は混ぜない
- ダッシュも**2つ連結** (`——`) が基本。全角マイナスや罫線は使わない
- `...` (半角ピリオド3つ) は使わない

## 4. 反復による情感表現の実例

同じ語を繰り返すことで、説明せずに感情の強度を伝える。`style-rules.md` A-5 の技法。

**パターン1: 同語反復**
```
（なんで泣いてるの。……分かってるくせに。——ばかみたい）
```

**パターン2: 半ばで切る**
```
（ちがう。ちがう、ちがう——）
```

**パターン3: 疑問形の連鎖**
```
（いつから? ……いつからだっけ)
```

## 5. 疑問形と断定形の使い分け

| 形 | 効果 | 使う場面 |
|---|---|---|
| 疑問形 | 迷い・気づきかけ・自問 | 感情が動いている瞬間 |
| 断定形 | 決意・確信・諦観 | 決断の直後、割り切り |

**疑問→断定の移行**は感情の転換を表現する強力な技法:
```
（好きなのかな。……好きだ。——好きだ)
```

## 6. 複数人の内心をどう切り替えるか

**原則: 1シーン1視点**。同一シーン内で視点キャラを切り替えない。

やむを得ず切り替える場合:
- **空行2行** (1行の空白) で明示的に区切る
- 新視点の最初の段落で、視点キャラの名前を地の文の主語に置く

**◎良い例**:
```
（……またこの笑い方だ）
 柊一は豆の袋を棚に戻した。


 千影はその背中を見ていた。
（柊一くん、また固まってる)
```

**✗悪い例** (段落内でザッピング):
```
 柊一は胸が苦しかった。千影も同じ気持ちで、でも律はそれに気づかず——
```

---

## 7. シーンごとに視点を固定することの重要性

視点を固定することは読者の感情移入の前提。章単位・シーン単位で視点キャラを事前に決め、そのキャラが**見て・聞いて・感じたこと**だけを書く。

**視点キャラが知らないことは書かない**:
- 他キャラの内心 (括弧書きの心の声)
- 他キャラの過去・経歴 (視点キャラがまだ知らないもの)
- 場外で起きていること

**視点キャラが知らないことの扱い**:
- 推測として書く: `（きっと何か考え事をしているんだろう）`
- 外面描写に留める: `千影は眉をかすかに寄せた`

## 8. 視点違反の頻出パターンと回避

| ✗パターン | ◎代替 |
|---|---|
| `柊一視点で (マスターの目が怖い)` | `千影の目が細くなった。柊一は思わず後ずさった` |
| `柊一視点で (千影は不安だった)` | `千影は唇を噛んだ` |
| `柊一視点で地の文: 千影は昔から人見知りだった` | (視点キャラが知らない情報は書かない、または別シーンで明かす) |
