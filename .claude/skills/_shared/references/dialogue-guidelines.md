# 台詞 ガイドライン

**このファイルの目的**: 台詞を書く/チェックするときの具体的な指針。定量ルール (80字上限) は `style-rules.md` B節を参照。ここでは「どう書くか」の技法を扱う。

参照元: `novel-write` (台詞を含む章を書くとき)、`novel-check` (台詞のチェック時)

---

## 1. 長台詞を相手の反応で分割する

80字を超える台詞は**必ず**相手の反応 (相槌・表情・動作) で分割する。口頭で読んで息が続かない台詞は不自然。

**✗悪い例** (155字):
```
律「俺はもう、ずっと先生が大好きでした! 好きじゃなかったらあんなに差し入れもプレゼントもしないですよ! 全部、全部先生と会って話すための口実です!」
```

**◎良い例**:
```
律「俺はもう、ずっと先生が大好きでした」
 千影が息を呑む。
律「……差し入れも、プレゼントも、全部口実です」
 千影は何も言えない。律は続ける。
律「先生と、会って、話すための」
```

**分割の挟み方**:
- 相手の**動作**: `千影が息を呑む`
- 相手の**表情**: `千影の目が見開かれる`
- 相手の**短い台詞**: `「え、」`
- 話し手の**動作**: `律は一度深く息を吸った`
- **沈黙**: `一拍の間があった`

## 2. 「……」の効果的な使い方

三点リーダは**沈黙・言いよどみ・間** を表す。台詞全体を「……」で埋めるのは濫用。

### 寡黙系キャラ

**◎良い例**:
```
「……うん」
「……別に」
「……どうかな」
```

### 感情が溢れて言葉にならない場面

**◎良い例**:
```
「……ごめん」
「……、」
```

### 言いよどみ

**◎良い例**:
```
「あの、……その、」
```

**注意**:
- 三点リーダは**2つ連結** (`……`) が基本
- `...` (半角ピリオド) は使わない
- 1キャラの全台詞が「……」まみれにならないよう注意 (キャラが薄くなる)

## 3. 口調の一貫性

キャラごとに以下を事前に規定し、章をまたいで一貫させる:

| 項目 | 例 |
|---|---|
| 敬語 / タメ口 | 千影: 誰にでも敬語 / 柊一: 親しい相手にはタメ口 |
| 語尾 | 律: 「〜です・ます」基調、感情高ぶると「〜っす」 |
| 呼称 | 千影→柊一: 「柊一くん」 / 柊一→千影: 「マスター」 |
| 一人称 | 律: 普段「僕」、感情が昂ると「俺」 |
| 方言 | ひなた: 関西弁 (「〜やん」「〜やろ」) |

**ルール化されていない揺れは禁止**。感情で揺れる場合も事前にキャラ設定で規定する。

## 4. 告白・決定的台詞を「短く」決める

告白・決別・決意のような**決定的な一言**は、短い方が重い。説明・言い訳・根拠を添えない。

**◎良い例**:
```
律「俺はもう、ずっと先生が大好きでした」
```
(1発話で17字。短いが決まっている)

**✗悪い例**:
```
律「俺はもう、ずっと先生が大好きでした! 好きじゃなかったらあんなに差し入れもプレゼントもしないですよ! 全部、全部先生と会って話すための口実です!」
```
(説明が付いた瞬間に告白が言い訳になる)

**原則**: **重い台詞ほど短く**。軽口は長くてもよい。

---

## 5. コメディ台詞と感情台詞の長さの違い

**コメディ台詞は長くてよい場合がある**。漫才的なツッコミ・捲し立て・早口は長さ自体が笑いになる。この場合は80字制限に従わない。

**◎良い例 (コメディで長い台詞が効く)**:
```
律「いやいやいやちょっと待ってくださいそれおかしいですよね!? 先生さっき自分でそう言ったじゃないですか! 俺ちゃんと聞いてましたよ!?」
```

**感情台詞は短く**。

**◎良い例 (感情台詞は短い)**:
```
律「俺はもう、ずっと先生が大好きでした」
```

**判定基準**: 読者に「笑わせたい」なら長くてよい。「刺したい」なら短く。

---

## 6. 漫才的ツッコミの扱い

コメディ作品でツッコミを書く場合:
- ツッコミ役の台詞は**即応性**が命。間を空けない
- 地の文の説明を挟まない (テンポが死ぬ)
- ツッコミは短い1発、または長い捲し立ての2種類。中間は弱い

**◎良い例 (短い1発)**:
```
柊一「ナポリタン、オムライス、カレー……」
律「多すぎます」
```

**◎良い例 (長い捲し立て)**:
```
柊一「ナポリタン、オムライス、カレー……」
律「いやこのラインナップ普通じゃないですよ!? なんでカフェにカレーあるんですか!? しかも三種類!?」
```

**✗悪い例 (間が空く)**:
```
柊一「ナポリタン、オムライス、カレー……」
 律は少し困った顔をした。このラインナップは確かに普通ではない。
律「多すぎます」
```
→ 地の文で間が空いてツッコミのキレが死ぬ。

## 7. 状況説明を台詞でやらない

「ご存知の通り」話法は禁止 (`forbidden-patterns.md` 4 番参照)。

**✗悪い例**:
```
「ご存知の通り、このカフェは三年前から駅前で営業していて、マスターの柊一くんは大学を卒業したばかりで——」
```

**◎代替**: 情報は地の文の一瞬の描写、または新規登場人物への自然な説明として分割する。

---

## 8. 沈黙の描き方

沈黙は台詞ではなく**地の文**で書く。台詞を空欄にしない。

**✗悪い例**:
```
柊一「……」
千影「……」
柊一「……」
```

**◎良い例**:
```
 しばらく、どちらも何も言わなかった。カフェの BGM がやけに大きく聞こえる。
 先に口を開いたのは柊一だった。
柊一「……すみません」
```

## 9. サブテキスト（言外の意味）の技法

**なぜ重要**: 人間は思ったことの半分も口にしない。キャラが内心を全て言葉にすると「AIが書いた説明文」になる。**表面の会話と裏の意味が異なる**のがリアルな会話。読者は「本当はこう思ってるのに！」と気づく快感を得る。

### 9-1. 話題の回避（核心を避ける会話）

本当に聞きたいこと・言いたいことを避け、別の話題で会話を続ける。

**✗悪い例** (直球すぎる):
```
律「先生のこと、好きです」
千影「えっ……」
律「好きなんです。どうしたらいいか分からなくて」
```

**◎良い例** (核心を避ける):
```
律「先生、明日の差し入れ何がいいですか」
千影「何でもいいよ」
律「……じゃあ、先生の好きなもので」
千影「私の好きなもの？ うーん……」
律「何でもいいです。先生が選んだものなら」
```
→ 「好き」を言わずに「好き」が滲んでいる。

### 9-2. 質問に質問で返す（答えたくない時）

直接答えると核心に触れてしまう質問を、別の質問で返す。

**◎良い例**:
```
彩音「律くん、あの先生のこと好きなの？」
律「彩音ちゃんはさ、マスターのコーヒーと先生のコーヒー、どっちが好き？」
彩音「……話逸らさないでよ」
律「逸らしてないよ。大事な質問」
```

### 9-3. 過剰な親切（罪悪感・後ろめたさの表れ）

嘘をついている・隠し事がある時、人は相手に優しくなる。

**◎良い例**:
```
 千影はいつもより丁寧にコーヒーを淹れた。ラテアートまで描いた。
千影「今日は特別に。……いいでしょ、たまには」
 柊一の目が少し細くなった。千影がラテアートを描くのは、何か後ろめたいことがある時だけだ。
```

### 9-4. 非回答（聞かれたことに答えない）

最も強力なサブテキスト。答えないことで、答えの内容が推測できてしまう。

**◎良い例**:
```
柊一「昨日、誰かと一緒だった？」
千影「……コーヒー、おかわり要る？」
```
→ 「要る？」は返事ではない。読者は察する。

### 9-5. 本音と建前の乖離（言い訳としての会話）

行動の本当の理由を別の理由で覆い隠す。

**◎良い例**:
```
律「先生、これ余ったんで」
 ——余ってない。朝から作った。
千影「ありがとう。……また余ったの？」
律「うちの母が作りすぎるんで」
 ——律の母は料理をしない。
```
→ 嘘と真実を地の文で並べるだけで、読者は全てを察する。

### 9-6. 沈黙と間（言わないことが最も雄弁な台詞）

**セクション8の「沈黙の描き方」**との併用。会話の途中で「答えるべきタイミングに答えない」ことで、言葉以上の情報を伝える。

**◎良い例**:
```
彩音「私のこと、どう思ってる？」
 律はコーヒーカップを両手で包んだ。温かい。外は寒い。
 彩音はその沈黙を、三秒だけ待った。
彩音「……いいの。聞かなかったことにする」
```
→ 答えなかったこと自体が答えになっている。

**原則**: **キャラの感情が強いほど、台詞は短く・間接的にする。** 本当に大事なことを正面から言えるのは物語の最終盤だけ。途中経過では常にサブテキストで匂わせる。
