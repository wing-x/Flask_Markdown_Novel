# 新規プロジェクト作成スキル

`projects/` 配下に新しい小説プロジェクトを作成します。

## 対象

`projects/$ARGUMENTS`

## ファイル参照スコープ

- プロジェクト直下（`projects/$ARGUMENTS/`）のファイルのみを参照すること
- `_old/` やその他のサブディレクトリ内のファイルは一切参照しないこと
- **例外**: `projects/$ARGUMENTS/part*/` ディレクトリ配下の章ファイル（`chapter*.txt`）は最新版として参照する

## 手順

### ステップ1: 事前チェック

- `projects/$ARGUMENTS` が既に存在しないか確認する
- 既に存在する場合はユーザーに通知し、上書きするか確認を取る

### ステップ2: プロジェクトの種類を確認

ユーザーに以下を確認してください：

**A. 単体作品**
- `projects/$ARGUMENTS/` 配下にテンプレートファイルを作成

**B. シリーズ作品（新規シリーズ）**
- シリーズ名と第1巻のタイトルを確認
- シリーズ聖典ディレクトリ `projects/_series_{シリーズ名}/` を作成
- 第1巻ディレクトリ `projects/{シリーズ名}_vol01_{巻タイトル}/` を作成

**C. シリーズ作品（既存シリーズに巻を追加）**
- 既存の `projects/_series_*/` から対象シリーズを選択
- `_meta.json` から次の巻番号を算出
- 新巻ディレクトリ `projects/{シリーズ名}_vol{番号}_{巻タイトル}/` を作成

**foreshadowing.md:**
```
# 伏線マスターリスト

| ID | 内容 | 登場巻/章 | 状態 | 回収予定 | 関連キャラ |
|----|------|-----------|------|----------|------------|
| F-001 | （例）主人公の父が残した古地図 | 1巻2章 | 未回収 | 7巻以降 | 主人公、師匠 |

---

## 状態の定義

- **未回収**: まだ解決していない
- **回収済み**: 解決した（巻/章を記載）
- **意図的放置**: 読者への謎として維持

---

## 巻をまたぐ布石メモ

（次巻以降で使う予定の設定や展開の種）

```

**series_summary.md:**
```
# シリーズ巻別サマリー

> 各巻を書き終えたら「巻サマリー自動生成」で追記する。
> 過去巻はこのサマリーのみをコンテキストに使う（本文は参照しない）。

---

```

**_meta.json:**
```json
{
  "volumes": [
    {
      "order": 1,
      "title": "{巻タイトル}",
      "project_name": "{シリーズ名}_vol01_{巻タイトル}"
    }
  ]
}
```

#### シリーズ巻ディレクトリのテンプレート

巻ディレクトリには単体作品と同じ5ファイル(character.md / plot.md / plot_draft.md / idea_notes.md / worldbuilding.md)を作成する。ただし以下の2ファイルは、シリーズ作品向けに冒頭の注意書きを変更する：

**character.md（シリーズ巻用）:**
```
# キャラクター設定

> シリーズ共通キャラはシリーズ聖典(characters_master.md)を参照
> この巻固有の設定・変化のみここに記録する

## この巻での変化・追加設定

```

**worldbuilding.md（シリーズ巻用）:**
```
# 世界観設定（巻固有）

> シリーズ共通の世界観はシリーズ聖典(bible.md)を参照
> この巻で初登場・拡張する設定のみここに記録する

## この巻で追加・拡張される設定

## この巻独自の場所・用語

| 名称 | 説明 | 登場章 |
|------|------|--------|
|      |      |        |

```

**idea_notes.md(シリーズ巻用):**
```
# アイデアメモ（巻固有）

> Web版Claude等とこの巻のアイデアを練る作業ノート。
> シリーズ全体の世界観・キャラ核は聖典(bible.md / characters_master.md)を参照。
> この巻独自のアイデア・場面・葛藤を雑多にメモする。

---

## この巻のテーマ・問い

## 主要な葛藤・対立

## キーシーン・キーセリフ案

## 既存巻との差別化（過去巻と何が違うか）

## 没アイデア・保留アイデア

## 自由メモ
```

#### 既存シリーズへの巻追加時

- 巻ディレクトリのテンプレートファイルを作成
- `_meta.json` の `volumes` 配列に新巻のエントリを追加
